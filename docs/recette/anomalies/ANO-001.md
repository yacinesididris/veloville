# ANO-001 — Le rapport d'import ne récapitule pas tous les volumes demandés

Cas de test : REC-02          Statut : ouverte
Sévérité : S3                 Priorité : P3
Constatée le 15/10/2026 par nom non renseigné

## Environnement
Version V1 (commit ou tag non relevé), import exécuté sur la base de recette,
fichiers CSV Stations, Trajets et Incidents.

## Reproduction
1. Exécuter l'import des trois fichiers CSV.
2. Ouvrir le rapport d'import généré.
3. Comparer son contenu aux récapitulatifs attendus par REC-02.

## Attendu / obtenu
Attendu : le rapport fournit un récapitulatif complet par fichier des lignes
CSV, lignes importées, rejets et doublons écartés.
Obtenu : le rapport détaille les lignes journalisées, décisions et motifs,
mais ne fournit pas le récapitulatif global des volumes demandé. Les comptages
doivent être effectués manuellement.
